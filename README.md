# RiStore

RiStore is a responsive game store prototype created to practice and showcase my front-end development skills using Bootstrap.

## About the Project

A technical showcase project featuring responsive layouts, interactive UI components, and clean design patterns built entirely with Bootstrap.

### Purpose

- Showcasing proficiency in the Bootstrap
- Practicing mobile-first development
- Deepening my understanding of CSS frameworks
- Refining my workflow by utilizing Git and GitHub

## What i used

- HTML 5
- Bootstraps 5
